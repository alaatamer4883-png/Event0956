# منصة Gather & Roam لتأجير مستلزمات الفعاليات والرحلات البرية (باللغة العربية الكاملة)

منصة ويب متكاملة وعصرية متجاوبة بالكامل باللغة العربية (RTL) لشركة تأجير مستلزمات الحفلات والفعاليات الكبرى والرحلات الاستكشافية، مع ربط كامل بقاعدة بيانات **Firebase Firestore** ونظام تسجيل دخول للعملاء بالاسم ورقم الجوال.

## 🔑 كيفية عمل صفحة تسجيل الدخول (`login.html`)
1. يُدخل العميل **اسمه الكامل** و**رقم جواله**.
2. يقوم النظام بإنشاء أو تحديث ملف العميل في **Firebase Firestore** داخل مجموعة `customers`.
3. يتم حفظ جلسة العميل في المتصفح، ويظهر اسمه وصورته الرمزية في شريط التنقل العلوي لجميع الصفحات (مثال: "أهلاً، فهد").
4. عند انتقال العميل إلى معالج الحجز والدفع (`checkout.html`)، يتم ملء اسمه ورقم هاتفه تلقائياً دون الحاجة لإعادة كتابتهما!
5. يمكن للعميل تسجيل الخروج في أي وقت بضغطة زر من القائمة المنسدلة في الهيدر أو من صفحة حسابه.
